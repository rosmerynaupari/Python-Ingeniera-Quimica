# Python aplicado a la Ingeniería Química

Repositorio de materiales educativos y ejercicios prácticos del taller **Python aplicado a la ingeniería química: modelamiento, simulación y optimización de biomateriales**.

## Contenido
- Fundamentos de programación en Python.
- Librerías científicas: NumPy, Pandas, Matplotlib y SciPy.
- Modelamiento y simulación de biopelículas biodegradables.
- Optimización de formulaciones mediante Python.

## Herramienta
Los ejercicios se desarrollan en Google Colab.
